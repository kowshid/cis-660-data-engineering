# CIS 660 - Data Engineering

This repository contains course contents, and assignments for **CIS 660: Data Engineering**.

## Course Overview

An introduction to information storage, manipulation, retrieval, analysis, and modeling techniques. Topics include
database paradigms, data preparation, extract transform load processes, information pipelines, and large-scale
analytics.
